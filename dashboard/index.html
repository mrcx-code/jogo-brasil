O SISTEMA

Como funciona

O fluxo e as configurações atuais ▸

backlog → despacho → worktree → banca → funil → produção → dashboard

  • backlog — a fila oficial (o backlog aqui em cima). O de cima é o próximo; a ordem é sua.
  • despacho — o plantão pega o item do topo cujo território está desimpedido. Territórios disjuntos voam juntos; qualquer interseção é sequencial. src/jogo.ts é sempre exclusivo: um escritor por vez.
  • worktree — cada agente trabalha numa cópia isolada do repositório, para duas escritas não se atropelarem.
  • banca — trabalho visual ou sensível ganha uma banca nomeada no despacho (arte, historiador) antes de fechar.
  • funil — a integração é um merge do ramo, com os portões por exit code entre cada passo; QA cruzado (quem convive não julga) e segurança antes de entrar.
  • produção — a main publica sozinha na Vercel. Vermelho no ar passa na frente de qualquer fila.
  • dashboard — esta tela: pedidos, backlog, agentes ao vivo e as decisões.

FALE COMIGO

Conversa

Modo leitura — falar comigo exige entrar.

Dashboard privado do BRASIL. Tudo aqui vem do servidor: o que você responde some em qualquer aparelho. Ler é aberto; escrever exige entrar, e entrar é com um PIN — não um e-mail. A conta é uma só, o endereço dela é inventado (não é o seu), e nenhum e-mail seu é pedido, mandado ou guardado em lugar nenhum.

O PIN viaja só até o Supabase Auth deste projeto, que guarda um resumo criptográfico dele e mais nada. Neste aparelho ficam a sessão e o contador de erros de PIN — os dois somem quando você sai.

Fica também a fila de respostas que ainda não subiram (até 50, no máximo 200 KB): ela não some ao sair, porque apagá-la jogaria fora o que você escreveu. Ela sobe sozinha assim que a rede volta; e, se isso não acontecer sozinho — o navegador às vezes não percebe que a rede voltou —, ela sobe do mesmo jeito na próxima vez que você abrir a mesa.

Rodando local, fica também uma marca do último PIN recusado, que morre ao fechar a aba: é calculada a partir do PIN, mas não dá para reconstruir o PIN a partir dela — o PIN em si não fica guardado.

Quando uma resposta sua é recusada pelo servidor ou cai da fila local por excesso, o texto (até 20 delas) fica guardado neste aparelho para você copiar; a lista aparece assim que você abrir a mesa de novo, com um botão para apagar depois de ler.

Nada além disso é coletado: sem rastreio, sem cookie de terceiro, sem perfil.
